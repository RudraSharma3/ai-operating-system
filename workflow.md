# Standard Workflow

## 1. Discover

Read the project `AGENTS.md`, architecture, active task state, and relevant ADRs. Identify constraints and unknowns.

## 2. Plan

Define the desired outcome, acceptance criteria, likely files, risks, and verification strategy. Record material trade-offs as an ADR.

## 3. Build

Assign a single owner to implementation. Keep changes small, reviewable, and version controlled.

## 4. Verify

Run relevant automated checks. Use a separate reviewer or model for a focused review when the change is material.

## 5. Learn

Update architecture and decisions when the system changed. Capture verified lessons; log unverified mistakes as candidates.

## 6. Hand off

State what changed, how it was verified, remaining risks, and the next recommended action.
